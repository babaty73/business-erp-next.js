# BizManager ERP Frontend

Responsive mock-data-only ERP frontend for Next.js App Router, JavaScript, and Tailwind CSS v4.

## Screens
Dashboard, Employees, Departments, Inventory, Orders, Customers, Finance, Reports, Settings.

## Install
Copy the `app` folder into your existing Next.js project root (back up your current `app` folder first). Keep your existing `package.json`. No additional packages are required.

Run `npm run dev` and open http://localhost:3000.

All data is local sample data in React state. No backend, database, authentication, or API requests are included. Replace sample state and event handlers with your own backend integration.
